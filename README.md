# Unclaimed Money Finder

A free public service website that helps people find and claim their unclaimed money. This website searches a comprehensive database of unclaimed funds including forgotten bank accounts, uncashed checks, insurance payouts, security deposits, and more.

## Features

- **Free Search**: Search by name, city, and state to find unclaimed money
- **Comprehensive Database**: Mock database with various types of unclaimed property
- **Detailed Results**: View amount, type, source, location, and year for each match
- **Claim Instructions**: Step-by-step guidance on how to claim your money
- **Informational Pages**: About, FAQ, and Privacy Policy pages
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## What is Unclaimed Money?

Unclaimed money includes:
- Forgotten bank accounts
- Uncashed paychecks and refunds
- Insurance policy proceeds
- Security deposits
- Stock dividends and bonds
- Utility refunds
- Inheritances and life insurance benefits

## How to Use

1. Open `index.html` in a web browser
2. Enter your first name and last name (required)
3. Optionally add city, state, and ZIP code for more specific results
4. Click "Search Now" to search the database
5. Review your results and follow claim instructions

## Important Notes

- This is a demonstration website with mock data
- In production, it would integrate with official state unclaimed property databases
- The service is completely free - users never pay to search or claim
- All search operations are performed client-side for privacy
